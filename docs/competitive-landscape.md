# 相似产品与人生库的定位

调研日期：2026-09-18。方法：查看作者官网、产品帮助页、公开仓库 README 与论文摘要；没有购买、登录或逐一实测这些产品。下表中的竞品能力为来源所述，未展示的功能不能推定为不存在。没有采用营销页的面试率、用户量或打分来证明效果。

## 结论

类似产品已经存在，而且有相当直接的开源替代。长期保存经历、AI 改写、岗位匹配、职业知识库乃至证据台账都不能单独宣传为人生库首创。当前值得验证的定位是：**给国内大学生使用的、从日常记录开始的成长证据档案，帮助把课程、竞赛和实习积累成可追溯的简历素材。**

## 对比

| 产品或方法 | 官方/作者公开描述的相似能力 | 对人生库的含义 |
| --- | --- | --- |
| [BragDoc](https://www.bragdoc.ai/how-it-works) | 从 Git 提交提取成就、组织记录、生成报告；支持自选模型与自托管 | 长期成就记录和本地控制不是独有能力；我们选择不限于代码的大学经历 |
| [Resume Intelligence](https://github.com/rahulbsw/resume-builder/blob/master/README.md) | 本地插件，从多种批准来源构建证据、职业知识库、简历和面试材料 | 最直接的开源对照之一；不能声称「知识库＋证据＋简历」是新组合 |
| [Resume Evidence Builder](https://github.com/litongshuo-edu/resume-evidence-builder) | JSON 证据台账、声明状态、公开链接校验和严格成稿限制 | 证据化表达也已有实现；人生库要证明日常录入和跨年复用更贴合学生 |
| [Teal](https://www.tealhq.com/) | 定制简历、JD 关键词匹配、职位收藏与求职跟踪 | 岗位定制是通用能力，我们当前不具备完整投递管理体验 |
| [Huntr](https://huntr.co/product/ai-resume-builder) | 简历生成、岗位匹配、多个版本关联具体申请，也覆盖学生与应届生 | 版本管理和面向学生均非独有；我们的冻结附件与原始事实用于私人追溯 |
| [超级简历 WonderCV](https://www.wondercv.com/) | 中文简历模板、AI 优化、课程/社团等素材挖掘与多端使用 | 中文和大学生需求已有强替代；我们当前不应比拼模板数量或移动端便利性 |
| [Brag document 方法](https://jvns.ca/blog/brag-documents/) | 持续记录工作成果、影响、协作和反馈，回顾时再组织表达 | 普通文档就能解决部分遗忘问题；我们的价值必须超过多建一个文件夹 |

另有 [Resume Tailor 预印本](https://arxiv.org/abs/2605.05257) 描述长期职业库、多来源检索与出处追踪。它进一步说明这种思路已有先例；该文为单个候选人的小规模试验，不能作为人生库有效或能提高录用率的证据。

## 目前可以证明的特点

- **记录与表达分开。** `raw`、`facts` 和简历条目分层；条目引用事实 ID，不能直接引用私密或 uncertain 事实。这是结构约束，不是自动验真。
- **资料可带走。** JSON、Markdown、HTML 和附件都在独立本地目录，MIT 开源，不要求注册人生库账号。模型是否联网取决于宿主，不能宣传成完全离线或零成本。
- **保存证据副本与冻结版本。** 附件哈希可检测后续改动；已留档的简历和关联来源不随草稿更新。哈希不证明内容真实，留档不等于已经投递。
- **大学阶段的默认流程。** 允许先录入不完整经历，区分发生日期和录入日期、个人与团队贡献；专业用于探索，成长建议应产出可验证成果。这部分主要由 Skill 规则实现，尚无长期使用效果数据。
- **轻量宿主接入。** 核心脚本只依赖 Python 标准库；提供 Codex 安装器与 WorkBuddy 导入包。WorkBuddy 客户端验收状态见[安装文档](workbuddy.md)。

这些是目前可核对的产品选择，不意味着每项都优于所有竞品；真正的竞争优势需要使用反馈验证。

## 目前的短板

1. 记录依赖用户持续使用；没有自动收集邮件、校园系统或奖项信息。
2. 尚无真实用户留存、节省时间或简历质量提升的数据。
3. 当前主要是对话和静态本地页面，缺少移动端随手记与可直接编辑的成熟 UI。
4. 没有经过验证的专业—岗位能力图谱或实时校招 HC 数据库；建议仍依赖助手与输入来源。
5. 事实 ID 可追溯不代表每句话语义正确，简历 summary 等概括仍需人工核对。

## 下一步如何验证定位

先验证一条短流程：找几位不同年级、不同专业的学生，用少量非敏感经历完成「记一条 → 之后补证据 → 找回材料 → 按目标岗位整理一条简历」。观察首次记录能否自行完成、找回是否准确、个人贡献是否保留、缺项是否被如实标注。所有观察都记录实际结果，不预设成功率。

推荐宣传语：**从大学开始，把每段经历和证据收好；需要简历时，找得到、讲得清。** 不使用「首个」「最懂校招」「保证拿 Offer」「绝不幻觉」等未经验证的主张。
