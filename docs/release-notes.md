# 人生库 v0.1.0-beta.2

新增面向 WorkBuddy 的下载与安装入口：

- 下载 `life-library-workbuddy.zip` 后，通过 WorkBuddy「技能 → 添加技能 → 上传技能」导入；ZIP 根目录包含 Skill 及全部运行资源。
- 按 WorkBuddy 开放平台规范补齐中英文描述、作者及版本字段，主体指令与通用版保持一致。
- `workbuddy.json` 提供版本、下载 URL、SHA-256 和验收状态，便于下载页面读取。
- 增加中文安装说明与竞品调研，明确当前优势、已有替代与尚未验证的效果。

不依赖 asu，不需要调用 Codex 安装器。归档和生成页面仍需 Python 3.10+。已自动测试包结构和解压后脚本；尚未完成 WorkBuddy 桌面端导入和真实对话实测，也未上架官方技能市场。

## v0.1.0-beta.1

从大学入学开始保存经历、奖项、成果和证据，在需要写简历时，能找回自己真正做过的事。

首个公开测试版包含：

- 对话式记录和证据归档规则，原话、事实与简历表达分开保存。
- 本地时间线、搜索、简历与下一步视图。
- 简历事实引用、附件哈希检查和不会随草稿变化的版本留档。
- 专业与兴趣探索、带来源日期的岗位资料，以及可选的 asu 联动。
- Python 标准库安装器、完全虚构演示和安装包。

下载 ZIP 后解压，在包目录运行 `python -X utf8 tools/install.py`，然后在 Codex 对话中使用 `$life-library`。详细说明见仓库 README。

需要 Python 3.10+ 和能够读写本地文件、运行脚本的 AI 助手。页面是生成的本地视图；不包含后台同步、实时岗位数据库或自动投递。个人资料明文存储，AI 服务的数据处理方式取决于你选择的运行环境。

欢迎用虚构或脱敏数据提交使用反馈。
