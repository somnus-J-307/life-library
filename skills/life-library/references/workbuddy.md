# 在 WorkBuddy 中使用

本 Skill 不依赖 Codex 专属工具，也不要求安装 asu。使用当前 WorkBuddy 提供的本地文件和命令执行能力；工具名以当前环境为准。

首次使用时定位已经导入的本 Skill 目录，读取用户指定的数据目录。用当前可用的 Python 3.10+ 运行脚本；Windows 可探测 python 或 py -3，macOS 可探测 python3。路径有空格时正确引用参数，数据目录必须是安装目录之外的绝对路径。

用户可以直接说「使用人生库，记一条……」，不要求输入 Codex 的 `$life-library` 语法。允许先记录一条不完整经历，不要求先填完个人档案。用户询问推荐方向时，再补齐必要的专业、年级和兴趣信息。

若没有可用的 Python，说明缺少的运行条件；可以先借助文件写入能力保存原始记录，但不得声称已完成校验、页面生成或附件归档。不要擅自全局安装 Python、改 PATH、切换完全访问权限或创建后台服务。

修改数据后调用 check 和 render。以宿主实际提供的本地文件预览/打开能力展示 index.html，若无法预览则给出完整文件路径。不自动调用网页发布、云端产物分享、IM 推送或自动化功能。

用户说明资料仅供本地使用时，尊重其用途范围。提醒的重点是本 Skill 的存储脚本不联网，宿主 AI 对上下文的处理取决于用户所选服务；不声称 WorkBuddy 必然离线。

本项目验证的是分发包结构与解压后脚本行为，尚未完成 WorkBuddy 桌面端安装和真实对话验收。遇到宿主导入异常，保留错误信息和客户端版本，不将脚本测试通过视为客户端验收通过。
